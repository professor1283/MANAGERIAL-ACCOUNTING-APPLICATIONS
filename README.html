Northbridge Components MBA Master Budget Simulation

Windows launch: Double-click Launch_Budget_Simulation.bat. The application opens in the default browser at http://127.0.0.1:8080.

Access

  • Professor uses the existing password (local default 3150; use BUDGET_SIM_PROFESSOR_PASSWORD for hosted deployment).
  • Additional professor accounts: Professor 1 / 12345 and Professor 2 / 12345.
  • Students are preloaded from the class roster. On first access, a student enters the exact roster name and creates a five-digit numerical password. The same password is used on later visits.

What is included

  • Separate professor and student portals
  • Twelve integrated budget and financial-statement schedules
  • Automated 100-point grading and attempt controls
  • Roster-based Student Table, student addition, attempt reset, password removal, end-of-semester Student Table clear, solution view, and CSV score export
  • SQLite schema, data dictionary, audit logging, and optional Dynamics 365/Dataverse adapter

Portable Python runtime

The launcher uses a private runtime inside the application folder. When no runtime is present and Python is not installed, the launcher automatically downloads the official Python 3.13.5 embeddable package from python.org. No Python installation or programming environment is required.

Network and internet use

Devices on the same network can connect to http://<host-IP>:8080. For public internet use, deploy the folder to a secured server, use HTTPS, and place the database on persistent storage. Render deployments automatically honor the platform PORT value when BUDGET_SIM_PORT is not set.

Dynamics note: A licensed Microsoft Dataverse tenant and OAuth credentials cannot be embedded in the download. The local application is fully operational with SQLite; the included adapter and mapping files enable an institution to synchronize it with its own Dynamics environment.

Section A Sales Budget Update

Students enter quarterly budgeted unit sales. The application automatically calculates the annual unit total and budgeted sales revenue as Budgeted Unit Sales multiplied by Selling Price per Unit. Calculated fields are read-only and are validated again by the Python server.

End-of-semester clear

The protected Professor dashboard includes a two-stage Clear Student Table operation. It removes only the currently signed-in professor's student accounts, passwords, drafts, submissions, scores, and attempts while preserving professor accounts, assignment information, Canvas resources, and Render/GitHub deployment configuration.

Student learning support and Canvas grade PDF

Each budget section now includes a free Detailed Explanation, Answer Hint / Assistance using the student's professor-configured penalty, and a one-use-per-section Check My Work tool whose availability and penalty are professor-configurable. The workspace displays the current cumulative grade, raw score, penalty points, and completion count. After submission, students can download a PDF grade report for upload to Canvas.

Professor-specific Student Tables

Professor, Professor 1, and Professor 2 each have an independent Student Table and independent grading-policy settings. Changes made by one professor do not alter either of the other professors' rosters or policy values. Existing students migrate to the original Professor table so student login remains unchanged.
