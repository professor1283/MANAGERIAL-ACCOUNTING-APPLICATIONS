Canvas LMS Instructor Setup

This guide adds Canvas access to the existing Northbridge Components MBA Master Budget Simulation without changing its assignment content, grading, screens, budgets, or database schema.

Recommended semester configuration

  1. Deploy one class-wide copy of the application to an HTTPS-capable Python host. Keep data/budget_simulation.db on persistent storage.
  2. Before the first production launch, set BUDGET_SIM_PROFESSOR_PASSWORD to a private password and set BUDGET_SIM_NO_BROWSER=1.
  3. In Canvas, open Modules, add an External URL item, enter the hosted HTTPS simulation URL, and select Load in a new tab.
  4. Create student accounts in the application's existing Professor section. The application will preserve each student's drafts and attempts in the semester database.
  5. Use the existing Export Scores CSV control in the Professor dashboard for grade records.
  6. Use Backup_Semester_Data.bat on Windows or Backup_Semester_Data.sh on macOS/Linux to make regular database backups.
Why new-tab launch is recommended: Canvas pages run on a different web origin from the simulation. Some browsers or institutional privacy settings can restrict third-party cookies inside iframes. A new-tab launch avoids that class of login problem.

Optional iframe mode

If your institution wants the simulation embedded directly in Canvas, the simulation must be hosted through HTTPS. Set BUDGET_SIM_CANVAS_EMBED=1 and BUDGET_SIM_SECURE_COOKIES=1. The application will then issue a SameSite=None; Secure session cookie suitable for cross-site Canvas framing. If a browser still blocks the framed session, use the same URL in a new tab.

Student download

The included Student_Semester_Launcher.html can be placed in Canvas Files or Modules. Students download it once, enter the instructor-provided HTTPS simulation URL, and thereafter use it as a one-click launcher. This preserves the central semester database and avoids distributing instructor solution/grading source files.

Full application package

The complete application remains separately downloadable for instructor deployment and archival use. Because it contains server-side grading and solution logic, distributing the complete source package to students is not recommended for a graded semester course.
