Northbridge Components MBA Budget Simulation — Data Dictionary

Assignment case facts and requirements are housed in the professor access suite. Section A stores quarterly unit-sales values as student inputs and marks annual unit totals and sales-revenue amounts as system-calculated values. SQLite is the packaged local data store; the final column provides recommended Microsoft Dataverse mappings.
