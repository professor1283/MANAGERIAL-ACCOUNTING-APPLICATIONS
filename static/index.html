Instructor controls

Student Table

Each professor account has an independent Student Table. Only students assigned to the currently signed-in professor appear here. Rostered students create their own five-digit numerical password on first access. The password is stored in this table as plain text, as configured for this course. An InPrivate/Incognito window does not erase a password stored in the server database. Use Remove Password only when a student must return to first-time password creation; this does not delete the student's saved work or submissions.

Add Roster Student

The original uploaded class roster remains assigned to the original Professor account. Professor 1 and Professor 2 maintain their own independent rosters. Use this form to add a student only to the currently signed-in professor's Student Table. The student creates the five-digit password on first access.

End-of-Semester Student Table Clear

Use this only after the semester is complete and after any needed grade exports or backups are finished. This permanently removes student names, five-digit passwords, saved draft work, submissions, scores, and attempt history from the currently signed-in professor's Student Table only. The other two professors' Student Tables are not changed. Professor accounts, assignment information, Canvas access, Render hosting, and GitHub deployment remain unchanged.

Assignment Settings

These settings apply only to students in this professor's Student Table. They do not change either of the other professors' settings or students.
